🕘 થયેલી પોસ્ટ

⚙️ Telegram જોડાણ

એક જ વાર કરવાનું:
  1. Telegram માં @BotFather ખોલો → /newbot → નામ આપો (દા.ત. Cheaperzone Poster).
  2. BotFather જે token આપે તે નીચે નાખો.
  3. @Cheaperzonee ચૅનલ → Administrators → Add Admin → તમારો bot ઉમેરો (Post Messages ચાલુ).
  4. "ચેક કરો" દબાવો.
Token ફક્ત તમારા આ કમ્પ્યુટરના browser માં જ સચવાય છે, બીજે ક્યાંય નહીં જાય.

🟢 WhatsApp (Whapi)

whapi.cloud → Dashboard માંથી Token કૉપી કરીને અહીં નાખો, પછી "ચૅનલ/ગ્રુપ લાવો" દબાવી જ્યાં પોસ્ટ કરવી હોય તે ✔ કરો.
