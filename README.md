# Cheaperzone Telegram + WhatsApp Post Dashboard
Live: https://nakraninirav6313-afk.github.io/cheaperzone-dashboard/
- `index.html` – dashboard (search product → post to Telegram / WhatsApp)
- `products.json` – product list (updated nightly by `scripts/update_products.py`)
Tokens are stored only in the viewer's browser (localStorage), never in this repo.
